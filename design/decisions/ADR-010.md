# Context

CMP-002 reads parts of the traceability-level policy, but missing nested fields can
currently become false through permissive defaults. Risk-attestation applicability
and required phrases are also interpreted by hard-coded T1/T2 logic rather than by
an authoritative QG-005 contract. QG-003 and QG-005 therefore share one policy-
validation and self-protection boundary while retaining separate gate identities.

# Accepted decision

1. `constitution/policies.yaml` remains the sole operative authority for
   `traceability` and `risk_attestation`. Two focused JSON Schemas —
   `knowledge/schemas/traceability-policy-gate.schema.json` and
   `knowledge/schemas/risk-attestation-gate.schema.json` — validate contract shape
   only; they do not define operational policy values, and no generic gate/policy
   interpreter is introduced.
2. QG-003 (`traceability-policy`) binds to `policy: traceability`; QG-005
   (`risk-attestation`) binds to `policy: risk_attestation` with
   `scope.event: pull_request`. Each gate retains its own four/five-field
   identity; QG-003 carries no independent level list, since trace levels remain
   canonical only in `traceability.levels`.
3. The traceability-policy contract requires exactly `T0`/`T1`/`T2`, each with a
   non-empty `description` and a complete `requires` block
   (`upstream_intent`, `design`, `decision_or_contract`, `implementation`,
   `verification`, `risk_attestation`, all boolean, no unknown fields). The
   exact eight-value `escalation_triggers` set (`architecture`, `nfr`,
   `security`, `data_model`, `external_contract`, `reliability`, `compliance`,
   `migration`) and a non-empty `t2_path_triggers` list are mandatory; missing,
   malformed, duplicated, or unsupported values fail closed with no permissive
   `{}`/`[]`/`false` default.
4. `traceability.levels.<level>.requires.risk_attestation` is the sole
   deterministic risk-attestation applicability authority. The QG-005 level
   contract (`required_substrings`) determines evidence content only; an
   applicable level must select a non-empty contract, and a non-applicable
   level may carry a dormant populated contract without effect. No duplicated
   `if level in {"T1","T2"}` applicability logic is retained.
5. Base and proposed governance (gate + policy + schema, each read from its own
   revision) are loaded and enforced independently for every PR transition:
   for an existing task, base obligations use the historical base level applied
   to the surviving proposed evidence; for a task new to the proposed graph, its
   real proposed level is used as the lookup key in both revisions, so a
   proposed weakening cannot exempt the very task that introduces it; a base
   task that remains PR-relevant (declared, or path-matched) but is absent from
   proposed traceability fails closed, with no successor/lifecycle inference.
6. A migration-only compatibility adapter is pinned to the exact repository base
   authorized by Owner Gate B-A
   (`305d51446e3823f3b990668a2af120dc7b295d6e`). It requires QG-003 and QG-005 to
   exist exactly once at that base in their exact legacy four-field shape before
   any normalization occurs, never synthesizes a missing gate, never consults a
   proposed schema or proposed risk policy to interpret the legacy base, and is
   rejected at every other base and at the workspace.
7. FR-003, ADR-003 provenance behavior, implementation-path resolution, QG-001,
   QG-002, and QG-004 remain unchanged. Human accountability for semantic level
   classification and material risk judgment is preserved; deterministic
   validation checks declaration structure, policy completeness, applicability,
   and evidence presence, and does not decide semantic truth.

# Compatibility and exclusions

FR-003 remains historical and unchanged. Existing T0/T1/T2 evidence, implementation-
path resolution, change provenance, and QG-004 behavior remain compatible and are
verified by TEST-015 alongside the new QG-003/QG-005 behavior. QG-006 evidence,
Increment C (FR-010/ADR-011/DEV-016), and the QG-004 compatibility adapter are
outside this decision.
