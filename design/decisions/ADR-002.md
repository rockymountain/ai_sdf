# Context and authorization

The user explicitly authorized DEV-002 and the invariant that every implementation
path entry for an active T1/T2 task must resolve to an existing repository file.
This is T2 because previously accepted evidence can now fail the validator contract.

# Decision

Implement FR-002 in CMP-002 using filesystem checks and pathlib glob expansion.
Validate every entry, not merely whether any entry in the task resolves. Reject
directory-only matches, paths resolving outside the repository, and Git metadata.
Do not require Git tracking; validate the post-change workspace, including new files.

Interpret current tasks as all supported statuses except deprecated, superseded,
and retired. Keep existing literal-existence checks for all levels and statuses;
extend file-resolution checks only to current T1/T2 tasks. This avoids weakening
old checks or introducing a historical-evidence migration in this batch.

# Compatibility and consequences

No schema, constitution, ID convention, or PR evidence rule changes. Unmatched
globs and non-file evidence formerly accepted for current T1/T2 tasks now fail.
Python pathlib glob semantics apply to workspace resolution; existing PR diff
matching remains unchanged. Match existence does not prove implementation quality
or complete trace coverage of every changed file. Human approval requirements remain.
