# Context

Synchronous indexing couples API latency to indexing work.

# Decision

Introduce an explicit indexing queue abstraction. The Phase 0 implementation uses an in-memory adapter only to prove the SDF vertical slice; production durability is intentionally out of scope and must be revisited before production use.

# Consequences

- API flow becomes asynchronous.
- Queue semantics become an explicit architecture concern.
- Production rollout requires a durable adapter and operational evidence.
