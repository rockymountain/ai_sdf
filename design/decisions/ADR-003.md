# Finding and authorization

The existing policy could express T2 triggers but not coverage exemptions or
generated status. This finding and the proposed path categories were reported to
the user before editing. The DEV-003 request authorizes this bounded governance
extension and deterministic implementation. Classify it as T2: governance and the
PR validator contract change. Human authority over risk and policy remains intact.

# Decision

Add change_provenance to constitution/policies.yaml with default: required and
explicit exempt_paths/generated_paths lists. All source, tests, tools, canonical
design, governance, schemas, configuration, dependencies, infrastructure, migrations,
and unclassified paths require declared provenance. Documentation exemptions cover
README.md, PHASE0_AUDIT.md, docs/*.md, docs/*.pdf, docs/*.docx, and examples/*-pr-body.md.
Use the existing fnmatch path matcher; these docs patterns also match subdirectories.
Executable files under docs and canonical artifacts under design are not exempt.

AGENTS.md alone is classified as generated. Its canonical sources are
constitution/agent-runtime.yaml and constitution/principles.yaml, its generator is
tools/generate_agents.py, and CI must retain that generator's --check validation.
No output is generated merely because of its filename/directory. The list governs
coverage only; it does not replace reproducibility checks or execute policy commands.

Read classifications from the PR base commit via Git. Missing classification means
required coverage; malformed classification fails. Proposed policy is also validated
but cannot exempt its own diff. DEV-003's bootstrap therefore declares every changed
file. Future exemption changes become effective only after human-reviewed merge.
T2 triggers from both base and workspace take precedence over exclusions.

Allow repeated existing Traceability Task / Traceability Level blocks. Each block
ends at the next task declaration and carries that task's risk attestation. Check
each T1/T2 task's commit marker and changed-path intersection as before. Check each
changed path against the union of declared tasks, and require a covering T2 task
for every T2-triggered path. Reject duplicate, unknown, and malformed declarations.

Use git diff --name-only --no-renames -z base..head so deleted paths and both sides
of renames are checked and whitespace is preserved. Post-change existence checks
from DEV-002 remain unchanged: deletion/rename coverage may use a pattern that also
resolves to a surviving file. No historical evidence exception is added here.

# Compatibility and limits

Single-task PR syntax and artifact schemas remain valid. PRs formerly passing by
one overlapping path can now fail. Documentation-only PRs may omit task declarations
only when all changed paths are base-governed exclusions; if a declaration is supplied,
all its existing obligations still apply. T0 remains subject to human classification.
This check proves declared path coverage, not semantic relevance of code or glob breadth.
