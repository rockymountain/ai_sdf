# Intent

A fresh checkout must reconstruct the deterministic validation environment from
repository declarations, without depending on globally installed validation packages.

# Acceptance

One exact Python declaration is consumed locally and in CI. One dependency file
pins the complete validation runtime package set. A fresh isolated venv installs
compatible wheels, imports the packages, and reports matching actual versions.
Missing/mismatched declarations and non-isolated execution are detectable.
Canonical/QG-004 validation, the full suite, generated AGENTS.md, and real PR evidence
pass. Historical TEST-001 through TEST-004 remain unchanged.
