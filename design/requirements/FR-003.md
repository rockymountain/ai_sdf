# Intent

The user authorized DEV-003 to close the reverse traceability gap: touching one
declared implementation path must not allow unrelated significant changes to pass.

# Acceptance criteria

- Use Git diff as changed-file evidence, including deletions and both rename paths.
- Every significant path must match implementation.paths of a PR-declared task.
- Multiple declared tasks may collectively cover the diff; undeclared tasks cannot.
- Canonical governance explicitly defines exempt and generated paths. Unknown paths
  require coverage. A PR cannot introduce exemptions for itself.
- T2-triggered architecture/decision/contract/infra/migration paths require coverage
  by a declared T2 task even if an unrelated source file has coverage.
- Purely exempt/generated changes need no artificial task. Supplied declarations
  must remain valid, with per-task T1/T2 markers, path matches, and attestations.
- DEV-001 and DEV-002 validation and runtime behavior remain passing.
