# Intent

`control/learning/README.md` defines a learning lifecycle (`observed ->
validated -> promoted -> superseded`) but makes record creation discretionary
and defines no mandatory point at which an event's reusable-learning value is
assessed, and no mandatory mechanism for retrieving and applying
already-promoted lessons before material work. LSN records remain provenance,
never execution authority; only the artifact named by an LSN's
`promoted_result` carries operative weight.

# Requirement

At a material correction round, or at an Owner-issued delivery-closure or
non-delivery terminal outcome (`deferred`/`cancelled`) for a governed control
decision, the authorized actor for that event must record an explicit
learning disposition (`NEW_LEARNING_CANDIDATE`, `EXISTING_LEARNING_REINFORCED`,
or `NO_REUSABLE_LEARNING`) with a short evidence-based rationale. An
independent-audit verdict is evidence feeding that disposition, never a
standalone disposition trigger. Blocked or merely paused work without an
Owner-issued terminal decision remains open; any disposition recorded at a
correction round for it stays provisional.

Before material T1/T2 design or implementation work, or material CTRL-CHANGE
decision work, the executor must check `control/learning/` for promoted
lessons applicable to that work, using each lesson's `applicability` field
only as a discovery aid, and must derive any resulting mandatory check
exclusively from the accepted rule/control artifact identified by that
lesson's `promoted_result` — never from its `observation`, `root_cause`,
narrative, or `preventive_heuristic` fields. The independent auditor must
independently re-derive applicability from the same canonical evidence and
verify whether required checks were actually performed, rather than accepting
the executor's own determination.

# Acceptance boundary

- A learning disposition never creates, validates, or promotes an LSN, and
  never grants implementation or closure authority.
- Recording a disposition must never cause work to be marked complete or
  delivered merely to store it.
- Checking a promoted lesson's applicability grants no authority to perform
  the underlying work.
- The learning-disposition field is distinct from a control decision's
  existing `disposition` field (`delivered`/`deferred`/`cancelled`/etc.).
- This requirement does not retroactively require disposition on any
  historical control decision.
- This requirement does not introduce a generic learning engine, an
  LSN-per-event mechanism, or new runtime/provider architecture.
