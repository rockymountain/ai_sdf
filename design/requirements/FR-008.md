# Intent

QG-001 artifact-schema and QG-002 reference-integrity already have substantive
deterministic enforcement in CMP-002, but their canonical declarations are not
authoritative inputs to that behavior. Canonical truth must not coexist with an
independent hard-coded authority.

# Requirement

The canonical declarations for QG-001 and QG-002 must be validated and bound to
the existing validator behavior that enforces artifact-schema and reference-
integrity rules. A missing, malformed, disabled, duplicated, or unsupported
required declaration must fail closed.

The binding must reuse the existing artifact and reference checks. It must not add
a second schema engine, a second reference engine, or a generic policy interpreter.

# Acceptance boundary

- QG-001 and QG-002 remain separate canonical gates while sharing one bounded
  implementation increment.
- Each declaration has an explicit supported shape and is required exactly once.
- A proposed governance change cannot silently disable an applicable existing
  binding.
- Existing artifact identity, schema, relationship-type, reference-existence, and
  orphan-task semantics remain unchanged.
- QG-004 behavior and its pinned compatibility adapter remain outside this scope.
