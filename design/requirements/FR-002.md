# Intent

Unmatched implementation globs currently pass static validation, allowing fictional
implementation evidence. The user authorized DEV-002 to close this gap.

# Acceptance criteria

For each current T1/T2 task, every `implementation.paths` entry must resolve to at
least one existing repository file in the post-change workspace. Literal files
and globs with file matches pass; missing literals, unmatched globs, directory-only
matches, and files outside the repository fail. Each entry is checked independently.

Current means draft, proposed, accepted, active, implemented, or verified. Existing
validation for T0 and deprecated/superseded/retired tasks remains in force.
DEV-001 and its existing verification must remain unchanged and passing.
