# Scope

Generalize deterministic change-path ownership without changing DEV traceability.
The canonical `change_provenance.owner_kinds` mapping defines non-task owner ID
patterns and allowed paths. The initial and only configured kind is
`project_control`, whose `CTRL-CHANGE-NNN` IDs may cover `control/**`.

PR validation reads owner kinds, allowed paths, and exemptions from the PR base.
The proposed policy is structurally validated but cannot authorize a new kind or
broaden coverage for its own change. Every declared non-task owner requires an
exact commit marker and an ID unused in history reachable from the base.

DEV task declarations, implementation paths, commit-marker behavior, risk
attestations, default-required provenance, exemptions, generated paths, and QG-004
remain unchanged. Non-task owners never satisfy the independent requirement for a
T2 DEV task to cover T2-triggered paths.

# Classification

T0: this extends the deterministic governance engine and its declarations without
changing runtime behavior, accepted Phase-1 design, or existing DEV semantics.
