# Scope

Make the Git-backed traceability test fixtures deterministic at teardown. A
shared initializer disables automatic maintenance, detached maintenance, and
automatic garbage collection in each temporary repository before its first
commit. The fixtures retain normal `TemporaryDirectory` cleanup and all existing
test assertions.

# Classification

T0: this changes test infrastructure only. It does not change runtime behavior,
provenance semantics, canonical policy, Project Control, or accepted design.
