# Purpose

Implement FR-010 in CMP-002 only after the Project Owner accepts ADR-011 and selects
the authoritative QG-006 review-evidence source. Verify the eventual result with
TEST-016.

# Proposed scope

- validate required review-evidence presence and authoritative source;
- verify reviewer identity and authorization;
- bind evidence to the exact governed revision or change;
- enforce explicit approval/rejection and accepted self-approval semantics;
- reject stale, replayed, ambiguous, unauthorized, or rejected evidence;
- preserve human ownership of the semantic decision.

# Exclusions

DEV-016 does not automate semantic-risk judgment, treat deterministic PASS as human
approval, substitute runtime `HumanAuthorization`, implement a provider integration
before source acceptance, start M3, or authorize M4.

# T2 classification

`T2 PROPOSED`: the future change establishes a trusted human-authority and merge-
contract boundary with security, reliability, and compliance impact.

# Implementation-readiness boundary

DEV-016 is not implementation-ready. ADR-011 deliberately leaves evidence-source,
authority, and self-approval selection to the Project Owner. Its implementation
paths must be refined if the accepted source requires additional governed files.

# Lifecycle and M3 boundary

This task is proposed and not active. CTRL-CHANGE-009 is PRE-WINDOW design work;
DEV-016 is not yet a declared M3 observation.
